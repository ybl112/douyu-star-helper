# 斗鱼全民星推荐自动领取

一个 Tampermonkey（篡改猴）脚本，支持后台自动领取全民星推荐活动红包、奖池筛选、到账统计及每日上限自动停止。

当前版本：`2.0.5`

## 安装

1. 安装并启用 [Tampermonkey](https://www.tampermonkey.net/)
2. [点击安装脚本](https://raw.githubusercontent.com/ybl112/douyu-star-helper/main/douyu-star-background.user.js)
3. 停用其他同类领取脚本和此前的独立扩展
4. 打开斗鱼直播间（如 [6657](https://www.douyu.com/6657)）并登录
5. 点击左下角“星推” →“开始后台领取”，收起面板后即可切换到其他标签页

如果浏览器只下载了脚本文件，用文本编辑器复制全部内容，在油猴“添加新脚本”中替换模板并保存。运行时请保持浏览器和控制页开启。

首次安装需手动启动。刷新同一个控制页会恢复已开启的任务；手动停止、平台提示每日上限或因异常停止后，不会自动重启。达到当日上限后，次日需要手动启动。

## 自动更新

由 Tampermonkey 定期检查 GitHub 上的新版本，有更新时下载并安装。请在油猴设置中开启脚本更新检查，检查频率沿用油猴设置。

展开“星推”面板，标题下方会显示当前版本。点击“检查版本”可查询新版，有更新时会出现“更新到…”按钮；油猴菜单中也保留了“安装或更新到最新版”入口。

更新不会清空设置和领取记录；已经打开的页面需刷新后才会运行新版，建议先停止任务再刷新。面板检查仅访问 GitHub 的版本文件，不携带斗鱼登录信息。油猴若提示新增更新域名访问权限，请允许。

自动更新使用油猴的 [标准更新机制](https://www.tampermonkey.net/documentation.php?q=update_url)。

## 功能

- 自动发现活动房间，按实际金币奖池排序和筛选
- 后台打开工作页，自动静音，领取结束后关闭
- 工作页在页面加载初期处理Chrome后台动画帧暂停，初始化红包组件，不自动切换标签页
- 按红包ID读取官方页面的实际倒计时，不显示或使用估算时间
- 官方页面切换为可领取后尝试领取，服务端仍提示等待时固定间隔2秒复核，不逐次延长
- 未读到对应红包的倒计时或读取已失效时暂停领取，超时后跳过并保留重新检查机会
- 达到每日上限后停止全部任务，取消剩余请求并关闭工作页
- 实际到账统计、金币流水查询和本地记录导出
- 单控制页运行，支持从其他页面查看状态和停止任务
- 拖动面板标题栏或最小化后的“星推”按钮，分别记住位置并避免移出窗口
- 查询失败后延长重试间隔，登录失效或需要验证时停止

| 设置 | 默认值 |
| --- | --- |
| 最低金币总奖池 | 10000 |
| 同时后台房间数 | 2 |
| 扫描间隔 | 60 秒 |
| 每轮最多查询房间数 | 24 |
| 最长等待 | 600 秒 |
| 自定每日领取包数 | 0，表示不额外限制；仍在斗鱼提示上限时停止 |

筛选依据是总奖池，个人实际分到的金额由斗鱼决定。没有符合条件的红包时，等待下一轮查询。

## 运行条件

浏览器关闭、控制页被丢弃或冻结时，脚本无法保证继续运行。后台工作页仍会消耗浏览器资源。

2.0.5新增页面上下文访问权限，用于在登记的工作页内处理后台动画调度。更新后请停止旧任务并刷新控制页，再重新启动；油猴若要求确认新权限，请确认后再运行。

脚本使用当前斗鱼会话和动态请求字段，不要求粘贴 Cookie。登录凭证、CSRF token和红包领取 code 不保存到日志或导出文件。页面要求验证或限制参与时停止；平台规则与账号限制仍适用。
