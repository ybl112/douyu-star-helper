# 更新记录

## 2.0.4

- 移除按等待时长比例推算首次领取时点的逻辑，不再生成400秒等估算倒计时
- 按红包ID读取官方红包弹窗中的“秒后可抢”文字和可领取按钮状态
- 只显示实际读到的秒数；未读到或读取失效时显示“未读到倒计时”，不按估算时间提交
- 官方页面可领取而服务端仍返回等待时，固定2秒后复核，不再逐次延长至30秒
- 工作页提交前再次读取对应红包状态，避免使用过期或其他红包的时间
- 最长等待按页面实际剩余秒数校验，不再按API固定等待字段提前过滤
- 修正慢房间阻塞其他房间、停止后的迟到提交、并发自定包数预留和字符串化奖励回包处理
- 完成全流程检查，见[检查记录](REVIEW-2.0.4.md)

## 2.0.3

- 面板标题下新增当前版本、“检查版本”和发现新版后的更新入口
- 展开的面板可拖动标题栏，最小化后可直接拖动“星推”按钮
- 两种状态分别记住位置，窗口缩小后自动移回可见范围
- 拖动后不误触展开，收起、设置等按钮仍可正常点击

## 2.0.2

- 增加独立的版本检查文件，由油猴定期检查并更新脚本
- 油猴菜单新增“安装或更新到最新版”入口
- 自动校验版本号、更新地址及版本检查文件的一致性

## 2.0.1

- 补齐推荐房间的活动入口登记，工作页打开全民星推面板后再开始计时
- 领取请求改为由对应直播间的工作页提交
- 收到 `12006` 时复查红包状态，按间隔继续等待，取消固定5次后直接跳过的处理
- 截止时间固定在活动初始化后的合理范围内，避免重复读取完整等待时长导致无限延期
- 超时和暂时缺失的红包进入冷却后可重新检查，保留成功和已结束红包的去重记录
- 增加每次等待的请求次数、已等待秒数与红包状态记录

升级时先停止旧任务，更新油猴脚本后刷新控制页，再重新启动。
