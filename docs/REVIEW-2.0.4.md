# 2.0.4 全流程检查

## 已修正

- 删除 `waitSec × 比例` 的首次尝试计划，不再生成400秒等估算倒计时
- 最长等待改为按读到的实际秒数筛选，同金额排序也不再借用固定等待字段
- 只按红包ID读取官方节点的实际秒数与原生领取按钮，读不到或过期时暂停
- 将收到等待回复后的递增退避改为固定2秒复核，仍保留任务最大时限
- 独立处理不同房间的领取过程，避免一个慢请求挡住其他房间
- 房间查询完成及CSRF初始化后，再校验任务有效性和对应红包页面状态
- 为进行中的领取预留自定每日包数名额，防止并发提交超过设置
- 状态恰好丢失时暂停当前领取，不误报为所有任务异常
- 兼容官方回包中字符串化的奖品数据，错误格式仍不计入成功
- 房间发现和准备阶段也识别登录失效、验证与每日上限，不等到提交后才处理

## 检查范围

1. 候选房间发现、奖池核实、排序、门槛过滤和并发开页
2. 官方入口、对应红包ID、实际倒计时、过期状态及页面变化监听
3. 控制页与工作页命令匹配、单请求执行、超时、取消和迟到回复
4. 最新红包标识、动态CSRF、提交前复核及异常停止
5. 真实回包奖品统计、空奖品、成功去重和超时冷却
6. 平台每日上限、自定包数、跨天、手动停止及刷新恢复
7. 版本检查、自动更新文件、面板拖动、位置恢复和窄窗口布局

## 验证

- 69项自动回归测试及脚本语法检查
- 隔离Chrome中的实际脚本交互，包括页面倒计时节点变化和撤销任务
- 公开活动接口字段与官方红包组件代码核对

倒计时来源是官方页面当前显示的状态，不将其宣传为服务端提供的绝对开放时刻。脚本不自行生成替代倒计时。
