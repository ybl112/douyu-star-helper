# 2.0.5 Chrome后台初始化检查

Chrome会暂停后台标签页的动画帧回调，见[官方说明](https://developer.chrome.com/blog/background_tabs/)。斗鱼官方红包组件包含使用动画帧的初始化与动画流程，因此补充这一类后台挂起的兼容处理。

## 修正

- 在页面加载初期，仅为已登记、未过期且属于当前控制页的工作任务安装兼容处理
- 隐藏时以低频回调推进官方动画，回调时间仍来自浏览器真实时钟
- 不伪造可见状态，不切换标签页，不产生替代倒计时
- 前台保留原生动画调度，结束后恢复原函数并清理待执行回调
- 去掉领取记录的自动编号，保留时间与内容

## 对比检查

使用隔离Chrome 155页面构造同类动画帧初始化条件，并关闭测试工具默认的强制可见及后台限流豁免：

- 对照版2.0.4：工作页始终隐藏，初始化动画未执行，读数为空
- 修复版：工作页始终隐藏，官方样式节点在回调执行后生成，读到了73秒原文
- 执行过程中没有选择工作标签页，页面可见状态仍为hidden
- 77项自动回归检查、原有倒计时交互及面板交互检查通过

该对比验证针对动画帧挂起条件，不代表已在用户登录账号中完成端到端领取。浏览器直接冻结或丢弃页面时，页面脚本仍无法自行恢复。
