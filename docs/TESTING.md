# 测试说明

测试代码位于 `tests/background.test.cjs`，使用 Node.js内置测试工具、模拟时间与接口响应。运行 `npm test` 不会登录斗鱼或发起真实领取请求。

目前19项测试：

1. 按实际金币奖池排序，过滤门槛并优先选择金额最高的红包。
2. 没有符合条件的红包时，不自动降低门槛。
3. 同金额优先等待较短的，并排除已结束或异常的红包数据。
4. 按服务器返回的实际奖励统计到账。
5. 每日上限立即取消所有任务；同日禁止重启，次日需手动启动。
6. 达到自定每日包数后停止。
7. 每包最多5次请求，恢复时避免集中补发。
8. 领取请求超时后停止，避免盲目重复提交。
9. 已派完的红包跳过，不终止其他任务。
10. 鉴权失败、要求验证或异常响应时停止。
11. 停止后忽略迟到的房间查询结果。
12. 较慢的房间发现不阻塞到时间的领取任务。
13. 并发准备任务不超过设置的后台标签页数量。
14. 刷新候选列表后，已完成的红包保持去重。
15. 动态CSRF映射、北京时间日期与设置范围校验。
16. 空奖励红包计为零收益。
17. 连续三轮查询失败后停止，重试间隔逐次增加。
18. 设置变化后，开页前重新检查候选资格。
19. 启动时已达自定包数上限，就不打开工作页。
